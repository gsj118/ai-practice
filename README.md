실행에 필요한 모델·소스·테스트·문서는 포함하고, 설치된 패키지·가상환경·캐시·빌드 결과·MNIST 원본 데이터는 제외했습니다. 설치와 검사는 각 프로젝트 폴더에서 해당 README를 따라 실행합니다.
