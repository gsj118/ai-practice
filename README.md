## v1.5 최종본

사용자 검토를 마친 최종본입니다. 메모 정리·오늘 분량 고정·되돌리기·화면 배치·한국어 검수를 반영했습니다. README는 자동화로 줄어든 행동을 실제 사용 순서와 함께 설명합니다. 공개 앱과 제출 사본의 소스·배포 근거는 각 프로젝트 문서에서 확인할 수 있습니다.

현재 최종본의 근거는 프로젝트의 [검증 기록](%EA%B0%9C%EC%9D%B8%EC%9A%A9%20%ED%95%A0%20%EC%9D%BC%20%EA%B4%80%EB%A6%AC%20%EC%95%A0%ED%94%8C%EB%A6%AC%EC%BC%80%EC%9D%B4%EC%85%98/docs/validation.md)과 [디자인 기준](%EA%B0%9C%EC%9D%B8%EC%9A%A9%20%ED%95%A0%20%EC%9D%BC%20%EA%B4%80%EB%A6%AC%20%EC%95%A0%ED%94%8C%EB%A6%AC%EC%BC%80%EC%9D%B4%EC%85%98/DESIGN.md)에서 확인합니다. 최초 공개 당시의 제출 기록은 아래 별도 절에 보존했습니다.

- 최신 원본은 PC 메모 영역 확대, 완료·기한 경고 색 구분, 모바일 메모 진입·목록 복귀와 22개 파일의 한국어 전체 검수를 반영했습니다. 타입·lint·단위 112개·서울/뉴욕 각각 88개·production build·전체 브라우저 144개가 통과했고, 작은 화면 조정 뒤 관련 36개와 최종 4개도 재통과했습니다. 메모·날짜 변경·되돌리기의 기존 16개 시나리오도 포함합니다. 제출 사본은 같은 파일인지 바이트 대조로 확인했습니다.
- 코드·자료는 원본과 바이트 단위로 대조했습니다. 프로젝트 README만 제출 경로에 맞췄고 원본 `.github`는 제외했습니다. 손글씨 26개 파일의 SHA-256과 Git 상태는 변경 전 그대로입니다.

## 최초 공개 v1.5 갱신 확인 · 2026-11-20

개인용 할 일 관리 애플리케이션을 v1.5.0으로 갱신했습니다. README는 자동화의 사용 흐름, 직접 누르는 체험 링크와 실제 공개 화면을 중심으로 정리했습니다.

- 제출본의 프로젝트 파일 1064개를 원본과 바이트 단위로 대조해 일치했습니다. README만 제출 경로·과제 모음 링크를 안내하도록 조정했으며 원본 배포용 `.github`는 기존처럼 제외합니다.
- 한글·공백이 포함된 제출 폴더에서 `pnpm check` 통과: 타입·lint·단위 79개·서울/뉴욕 각각 55개·production build.
- 같은 제출 폴더에서 새 방문 자동 계획과 체험의 개인 저장소 보존 E2E 2개를 실행해 통과했습니다. 원본 저장소는 루트/Pages 경로 각각 117개 및 원격 CI/Pages 검사를 완료했습니다.
- 손글씨 인식 프로그램 26개 파일의 SHA-256이 변경 전과 일치합니다. 모델·소스·문서·README를 수정하지 않았고 이번에 재학습이나 재검사를 했다고 주장하지 않습니다.
